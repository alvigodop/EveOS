MODULAR PATCH WORKFLOW

This release is split into independent modules so future updates can contain only changed files.

BACKEND
server.py
- Local server
- Workspace access
- File reading/writing
- DOCX extraction
- Import/export
- Security boundary

FRONTEND
app\index.html
app\assets\css\app.css
app\assets\js\api.js
app\assets\js\state.js
app\assets\js\tree.js
app\assets\js\editor.js
app\assets\js\app\chains\
app\assets\js\integration\

LAUNCHERS
launch.bat
launch.ps1

PATCH FORMAT
Future patch ZIPs should preserve these relative paths and include PATCH-MANIFEST.json.
Extract the patch over the existing World-Book folder and replace only matching files.

BEFORE PATCHING
1. Export a snapshot.
2. Stop the localhost server.
3. Apply the patch.
4. Restart launch.bat.

Do not delete the data folder when applying patches.
