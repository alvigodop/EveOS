# Agent Nexus private-data contract

Agent Management and Nexus Browser remain separate owners. Agent profiles live in ignored `data/runtime/agent-management/agents.json`; Nexus room state lives in ignored `data/runtime/nexus-browser/dex-state.json` and its active browser mirror. Neither belongs in Git. The tracked `config/agents/tlo/AGENT.md` is the starter definition; edits go to ignored `data/runtime/agent-management/tlo/AGENT.md`. That private file is the effective authored TLO prompt when present. Legacy TLO JSON identity is read only when there is no override and it differs from the old default, so user edits are not discarded. `config/agents/tlo/ORIGIN.md` is reference metadata, never boot context.

Agent Management exposes the active definition path, editor, and origin excerpt. TLO's scoped projection includes the effective definition plus source, SHA-256 revision prefix, included-section list, and metadata-only list; the chat adapter constructs the prompt from the file, provider binding, and selected scope. TLO status exposes source/revision without the full file path. Private notes, provenance, unrelated agents/scopes, and the origin excerpt are not injected. The adapter reads the definition at each new request; a saved edit is effective on the next turn. The browser's conversation transcript remains in memory and New conversation clears it. The generic Local MoE Harness still owns model/runtime state.

## Portable bundle

Agent Management's Export and Import controls use `eveos.agent-nexus-portable` v1 JSON. The bundle includes normalized agent profiles, TLO's effective authored definition, and Nexus rooms, messages, participant names and provider identity hints. Room IDs, message IDs, participant IDs, and relationships are preserved. Machine-specific tab/target IDs, active relay/recovery/pending turns, browser profiles, sessions, credentials, logs, private notes, permissions, and hardware-specific model IDs are excluded. Imported room relays are stopped and participants must be reconnected before use. Origin metadata is tracked EveOS source, not duplicated into every private bundle.

Exports contain conversation text and may therefore contain private material entered by users. Treat downloaded bundles as sensitive user files; do not add them to Git. The API accepts at most 16 MiB and caps agent, room, participant, and message counts. It validates the entire bundle before planning an import.

Stop Nexus Browser explicitly before export, preview, or apply. This is a safety boundary: a running server or browser tab must not race an on-disk import. The UI does not stop it automatically. Import is add-only by stable ID. Identical IDs are skipped, differing IDs or an existing private TLO definition conflict block the entire transaction. There is no blind last-write-wins merge. Preview reports counts and conflicts; Apply recomputes the plan under locks, makes ignored backups under `data/runtime/agent-management/import-backups/`, commits the changed local files, and restores originals if a write fails. Reimporting an identical bundle changes nothing and makes no new backup.

For deterministic qualification use `python tools/smoke/agent_portability_smoke.py` and the Agent Nexus smoke profile. The smoke runs in temporary directories, not the real six-room Nexus store. The browser smoke exercises the definition editor and preview/apply controls with mocked API responses. Live export can be inspected without importing into personal data; an import proof should use an isolated temporary store.
